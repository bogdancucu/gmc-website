# GMC Proiect Construct – site

Site-ul [gmc-proiect-construct.ro](https://gmc-proiect-construct.ro), publicat prin Cloudflare Pages.

## Structură

- `site/` – fișierele publicate (HTML static). Cloudflare Pages servește acest folder.
  - `index.html` – pagina „site în lucru"
  - `assets/` – logo-uri, imagini, favicon

## Publicare

Fiecare push pe `main` declanșează automat o publicare în Cloudflare Pages
(Build command: gol · Build output directory: `site`).

## Urmează

Site-ul complet (Astro): Acasă · Măsurare radon · Remediere radon · Radon la locul de muncă ·
Clădiri noi și proiectare · Despre / Contact · Blog.
